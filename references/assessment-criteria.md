# Assessment criteria: writing for the top band

Read this when drafting, revising, reviewing or cutting any commentary. The bands below are paraphrased, not quoted. The official wording is in the current IB TOK subject guide, and the student's teacher has the final say. Check both before relying on this.

Contents: 1 The question the criterion asks · 2 What the top band looks like · 3 What each lower band gets wrong, and the fix · 4 Per-object checklist · 5 Whole-exhibition checklist · 6 How to use this in feedback

---

## 1. The question the criterion asks

Does the exhibition successfully show how TOK manifests in the world around us? It is judged on four things:

1. **Objects and real-world contexts:** three objects, each identified, each with its own specific real-world context.
2. **Links to the prompt:** each object clearly linked to the one chosen IA prompt, with the link explained.
3. **Justification of each contribution:** why each object is in the exhibition, and what that particular object adds.
4. **Support:** points backed by appropriate evidence and explicit references to the prompt.

The descriptors that go with the top band are convincing, lucid and precise.

## 2. What the top band looks like

- Each object is named and placed in a **specific, explicitly stated real-world context** (who made it or where it appears, when, and in what setting). The image shows that specific object, not a generic example of its type.
- The **link to the prompt is clear and well explained** for every object. The prompt's wording appears in the commentary, and the commentary answers it.
- The **contribution of each object is justified as particular**: what this object shows about the prompt that the other two don't.
- **All, or nearly all, points are supported** by appropriate evidence and explicit references back to the prompt.
- The writing is precise: every sentence says what it means, and nothing is there only to fill space.

## 3. What each lower band gets wrong, and the fix

| Band | What goes wrong | How to fix it |
|---|---|---|
| Good (7–8) | The link is explained, but with some lack of precision or clarity. Many points are supported, but not nearly all. | Tighten vague sentences (vague "this", unfinished "as…"). Find each unsupported point and give it evidence or a prompt reference. |
| Satisfactory (5–6) | Real-world contexts are stated vaguely or imprecisely. Only some explanation, some justification and some support. | State each context exactly. Explain the link in a sentence of its own. Add evidence to the remaining unsupported points. |
| Basic (3–4) | Contexts are only implied. Links are made but unconvincing or unfocused. Justification is superficial. Reasons are unsupported or not relevant to the prompt. Significant repetition across the objects' justifications. | State contexts outright. Replace "this relates to the prompt" with the specific reason. Delete reasons that don't answer the prompt. Make each object's justification different (see §5). |
| Rudimentary (1–2) | Contexts not stated, or a generic image of a type of object. Links minimal, tenuous or unclear. Very little justification. The commentary is mostly description or unsupported assertion. | Replace generic objects with specific ones. Turn description into a claim plus evidence. Spell out the link step by step. |
| 0 | The standard isn't reached, or one of the prompts isn't used. | Use one of the official prompts, with its wording. |

## 4. Per-object checklist

Answer yes or no for each object. Any "no" is a target for an edit or a comment.

1. Is the specific real-world context stated outright, with source, date and setting?
2. Is the image a specific object (not a stock image of the type)?
3. Does the commentary use the prompt's wording and answer it for this object?
4. Is there a sentence saying what this object adds that the others don't?
5. Is every claim backed by evidence from the object, a cited source or cited textbook theory?
6. Is description kept to what the argument needs? Does each descriptive sentence lead to a claim?
7. Does every sentence say something specific (no tenuous link, no "this shows" without saying what)?

## 5. Whole-exhibition checklist

1. Do all three objects link to the same prompt, each through a different route or angle?
2. Does each object's justification differ from the other two? Lower bands penalise repetition across objects, so look for identical reasoning, identical link sentences or the same theory used the same way three times.
3. Is the prompt answered a little more fully by the end than it was at the start?
4. Does the total fit the word limit, with the argument intact?

## 6. How to use this in feedback

- Tie each edit or comment to one of the four criterion strands, and say which descriptor feature is missing ("the context is implied, not stated").
- Never give a numerical mark or promise a band. Say which top-band features are present and which are missing.
- When cutting words, protect what the top band rewards: explicit context, prompt wording, evidence and the particular contribution of each object.
- Prioritise fixes in this order: unsupported points and weak links first, then vague contexts, then repetition across objects, then style.

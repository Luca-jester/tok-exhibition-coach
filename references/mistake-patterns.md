# Recurring mistake patterns in TOK exhibition drafts

Read this when classifying teacher comments and when scanning a draft for mistakes the teacher didn't flag. Examples are invented and only show the shape of each fix. Never copy them into a student's work.

## 1. Claim named but not justified
**Signs:** "Which? Why? Justify the distinction." The draft labels a claim (for example "belief or opinion", "reliable", "biased", "ethical") without choosing or explaining the label. This is most common in prompts about criteria or distinctions, but any prompt can have it.
**Fix:** Decide which label applies, then add the reason using the definitions or criterion from the theory. Commit to one label per claim. If a paragraph says "X or Y", split them and justify each separately.
**Example:** *Before:* "The sign's slogan is a belief or an opinion." *After:* "The slogan 'the best coffee in town' is an opinion, because it rests on personal taste that no shared evidence can settle."

## 2. Leaps ("So?")
**Signs:** "So? Why does this mean…?", "(Clarify what you mean here)". A fact is stated and a conclusion follows with no explanation.
**Fix:** Add the missing step in one sentence, "this matters because…". Edit the sentence before the comment, so the explanation sits where the leap happens.
**Example:** *Before:* "The sundial is in a university courtyard, so its claims are knowledge." *After:* "The sundial's markings follow the sun's measured position, which anyone can check, so its claims are justified by shared evidence."

## 3. Prompt wording missing
**Signs:** "Use the wording of the prompt", "Justify how this answers the IAP". The commentary describes the object well but never says how it answers the prompt.
**Fix:** Put the prompt's exact wording in the intro and again in the link sentence, and state the answer the object supports (the criterion, degree, influence or position, depending on the prompt; see `prompt-types.md`), not just the question. Vary the link between objects so each adds something.
**Example:** "This shows that we can tell [exact prompt wording] by asking whether a claim's justification can be checked by others." (Criteria prompt.) "This suggests that [exact prompt wording] is attainable only to a limited extent, because…" (Extent prompt.)

## 4. Theory missing or unapplied
**Signs:** "Add TOK theory…", "Support your point with theory", "Textbook?".
**Fix:** Put one to three sentences of cited textbook theory at the start of the paragraph, then connect it to a specific example from the object. If the student hasn't supplied theory, insert `[quote] (Author, year, p.__)` and ask for it. Never invent it. Keep hedged wording hedged.

## 5. Skipping justification
**Signs:** An object, institution or place is treated as settling a claim ("it is knowledge", "true from the beginning", "it proves…"). Justification or evidence is never named. This applies to any prompt that turns on whether a claim is reliable or well supported.
**Fix:** An object isn't a claim. Say that the claims it presents are justified (tested, reviewed, open to revision, backed by evidence), and name the justification in each paragraph. "Objectively true" can also clash with "open to revision"; "verifiable" or "justified" is safer.

## 6. Contradictions between paragraphs
**Signs:** "Decide which!", "Check this all flows". One paragraph calls a claim "partly X", another calls it Y. Or one paragraph says the object settles the question and another says it doesn't.
**Fix:** Pick the position and make both paragraphs agree. If something only looks like it sits between two positions, say that it appears to but is in fact one of them, and why.

## 7. Repetition
**Signs:** "No repetitions from above". The same point ("not by how it is presented", "the knower must judge") appears in several sentences or paragraphs.
**Fix:** Keep the strongest instance, usually where it answers the prompt, and delete the others. Let each paragraph's link add something new.

## 8. Unfinished or vague sentences
**Signs:** Trailing "as…", "between what?", "this explains how…" where "this" has no referent, "both attributes" when three are listed.
**Fix:** Finish the thought with its reason ("as…" needs a because), name the categories, replace "this" with the noun, and count the items.

## 9. Overlong quotes
**Signs:** "Shorten", "Clarify your point". A long quotation does the work the student should do.
**Fix:** Quote only the phrase that carries the idea, or paraphrase, and add one sentence tying it to the object. Check the quotation marks are balanced.

## 10. Neighbouring concepts blurred or the contrast step missing
**Signs:** "What about the difference between X and Y?" The commentary shows one side only: one category when the prompt names several, one end of a comparison, a claim with no limit, or a position with no opposing view.
**Fix:** Add the contrast step that suits the prompt (see `prompt-types.md`). For a prompt that names categories, show how each differs from the other two, with a different example for each. For an extent prompt, give the limit. For a comparison prompt, give the other side. For an ethical prompt, give the strongest opposing view.

## 11. Authority treated as proof
**Signs:** "It is at a famous institution, so it is peer reviewed." The reputation of a place or maker stands in for justification of a specific claim.
**Fix:** Move the justification to the claims. Say the claims were tested or reviewed by a community, and use the institution only as evidence of that community.

## 12. Method mismatch
**Signs:** A theory sentence says "tested using the scientific method", then an example is justified by mathematical proof, or the other way round.
**Fix:** Say that each area of knowledge has its own accepted methods, or choose an example that fits the stated method.

## 13. Missing knower
**Signs:** The theme is about the knower, but the knower appears only in the last line.
**Fix:** Add what a knower can do with the distinction: check the justification, notice confident language, use reason and memory. Keep it to one or two sentences in the link.

## 14. Unsupported superlatives and figures
**Signs:** "The most important", "the most widely used", precise numbers with no source.
**Fix:** Cite the source, or soften ("some of the most important", "foundational"). Tell the student to check each number against the source themselves.

## 15. Concepts and tools missing
**Signs:** "Add TOK concepts", "Add links to cognitive tools".
**Fix:** Work the concepts and tools into existing sentences where they change the meaning. See SKILL.md for the lists and matching.

## 16. Grammar and punctuation
**Signs:** Comma splices, missing punctuation after a title or quote, capital after a semicolon, "theorem or theory" instead of "and", citation placed after the full stop, stray apostrophes in quotes, typos.
**Fix:** Correct silently and list the corrections in the change log. Never change a quotation's wording while fixing punctuation.

## 17. Citations and references
**Signs:** "Add all sources", missing page numbers, a web source cited by site name only, the same source with two different dates.
**Fix:** Use author-date citations with page numbers for the textbook. Give every in-text citation a reference entry. Order the reference list alphabetically by author surname, and include the textbook. Check dates are consistent for the same source.

## 18. Word count
**Signs:** "Shorten so the whole object is around N words", or a total limit over three objects.
**Fix:** Use the cutting order in SKILL.md and protect the theory, concepts, tools, prompt wording and link. Do the cutting last, after the argument works. Count before and after and report what was cut.

## 19. Description instead of analysis
**Signs:** Sentences that say what the object is, looks like or contains, with no claim attached. The commentary reads as a caption. At the lowest band, the commentary is mostly description or unsupported assertion.
**Fix:** For each descriptive sentence, ask what claim it supports. If there is one, add it ("…which shows that…"). If not, cut the sentence. Keep only the description the argument needs.
**Example:** *Before:* "The sundial is made of bronze and has twelve engraved lines." *After:* "The sundial's engraved lines follow the sun's measured position, which anyone can check, so its claims rest on shared evidence."

## 20. Generic object or vague real-world context
**Signs:** The context is implied ("a famous painting") or missing. The image is a generic example of a type (any sundial) rather than the specific object. No source or date.
**Fix:** State the context outright: creator or source, date, and where it appears or what it is part of, with a citation. Use an image of the specific object with a caption. If the student can't find a specific context, the object may need replacing.
**Example:** *Before:* "My object is a sundial." *After:* "My object is the sundial in [named place], installed in [year] by [maker] (Source, year)."

## 21. Same justification across objects
**Signs:** All three objects justified with the same reason, the same theory used the same way, or link sentences that differ only in the nouns.
**Fix:** Give each object its own contribution to the prompt: a different angle, a different area of knowledge, a different part of the question (for example one shows the criterion met, one shows it failing, one shows its limits). Add one sentence per object saying what it adds that the others don't. Rewrite repeated links so each ends on a different point.

## 22. Link is tenuous or unclear
**Signs:** "This relates to the prompt" with no reason, a connection that needs several unstated steps, or a sentence where it is hard to tell what the student means.
**Fix:** Spell out the link in order: object feature, then claim, then what that says about the prompt. If a step can't be written down, the link is too weak, so either find the missing evidence or drop the claim.
